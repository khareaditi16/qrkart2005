# 🛒 QRKart – Empowering Street Vendors with Tech 💡

QRKart is a modern web platform designed to uplift and support street vendors through digital tools. It provides vendors with QR-based identity, digital profiles, geolocation tagging, multilingual access, alert systems, and more — making it easier for authorities, citizens, and vendors to connect efficiently.

---

## 🚀 Features

- ✅ Vendor Registration with UPI ID & Cart Status
- 📍 Geolocation Tagging
- 🌐 Multilingual Support 
- 🆔 QR Code-based Identification (Aadhaar & Municipal linked)
- 📣 Real-Time Alerts & Notifications
- 🛠️ Cart Renovation Tracker
- 💰 Microloan Access Portal
- 🔒 Admin Panel with Verification Tools
- 📊 Dashboard for Vendors and Admins

---

## 🛠️ Tech Stack

### Frontend
- **React.js** with TailwindCSS
- React Router DOM
- i18n for Language Toggle

### Backend
- **Node.js**, **Express.js**
- **MongoDB (Cloud Atlas)**
